# homebridge-apcaccess

This project was an [apcaccess](https://github.com/mapero/apcaccess) wrapper for [Homebridge](https://github.com/nfarina/homebridge).

I bought some NMCs so no longer maintain this project, but luckily, a new project has succeeded this one, which works as a drop-in replacement for this project: https://github.com/santiagosony/homebridge-apcaccess2

I'd recommend you go and check that project out!
